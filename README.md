# teakhuis-dordrecht
Ontwerpvoorstel (Astro + Tailwind 4) voor Teakhuis B.V. (teakhuis.nl), online en op bestelling.
Bouwen in demomodus: `PUBLIC_VOORSTEL=1 npx astro build`, preview: `npx astro preview --port 4447`.
Bronnen van feiten en foto's: src/data/site.ts (commentaar), src/assets/BRONNEN.txt, map bron/ (crawl teakhuis.nl).

# Teakhuis website

Website van Teakhuis B.V. (teakhuis.nl): teakhouten meubels op maat, alles op aanvraag via een offertelijst.
Astro 7 + Tailwind 4, statisch op GitHub Pages, beheer via Sveltia CMS op `/admin`.

- Ontwikkelen: `npm ci`, `npm run dev` (http://localhost:4447)
- Bouwen: `npm run build`, bekijken: `npm run preview`
- Beheer en livegang: zie [BEHEER.md](BEHEER.md)
- Ontwerpkeuzes: zie [PLAN.md](PLAN.md)
